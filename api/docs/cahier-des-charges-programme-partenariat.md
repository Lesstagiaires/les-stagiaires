**Objectif** : développer un véritable Programme de Partenariat LES STAGIAIRES afin que
les entreprises deviennent des partenaires engagés dans l'employabilité des jeunes
Africains.

## Objectifs

- Renforcer la marque employeur.
- Démontrer l'engagement sociétal (RSE).
- Valoriser l'investissement dans la jeunesse africaine.
- Accroître la visibilité sur la plateforme.
- Attirer les meilleurs talents.

## Module Programme Partenaires

- Gestion des demandes de partenariat.
- Validation par les administrateurs.
- Renouvellement et historique.

## Badge officiel

- Attribuer automatiquement un badge officiel.
- Afficher le badge sur la page entreprise, les offres, les recherches et le tableau de
  bord.

## Label Entreprise Citoyenne

- Créer un score évolutif fondé sur des critères objectifs : stages publiés, stagiaires
  accueillis, évaluations, recrutements, ancienneté, etc.

## Tableau de bord Impact

- Jeunes accompagnés.
- Stages réalisés et en cours.
- Emplois créés.
- Pays, villes et établissements partenaires.
- Mentorat réalisé.

## Rapport annuel d'impact

- Générer un rapport PDF annuel avec statistiques, graphiques et indicateurs d'impact.

## Avantages de visibilité pour l'entreprise ou partenaires

- Mise en avant sur la page d'accueil.
- Priorité dans les recherches.
- Campagnes de communication.
- Une page vitrine présentant ses métiers, ses valeurs et ses opportunités.
- Une mise en avant sur la plateforme et lors des campagnes de communication.

## Architecture technique

- Nouvelles tables de base de données.
- API REST sécurisées.
- Pagination, filtrage, journalisation et tests.

## Administration

- Accepter/refuser les demandes.
- Suspendre un partenaire.
- Consulter les statistiques et l'historique.

## Design

- Respecter le nouveau Design System.

## Avant l'implémentation

- Présenter le modèle de données.
- Présenter l'architecture technique.
- Présenter les écrans.
- Décrire les parcours utilisateurs.
- Identifier les impacts sur les modules existants.
